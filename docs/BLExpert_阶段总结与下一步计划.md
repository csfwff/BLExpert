# BLExpert 阶段总结与下一步计划

## 当前阶段：BLE 基础通信可用

截至当前阶段，BLExpert 已完成 Flutter 调试工作台和 BLE 基础通信主链路，能够用于真实设备的扫描、连接、特征发现、读写和通知调试。

## 已完成内容

### 工程与界面

- 已建立跨平台 Flutter 工程，目标覆盖 Android、iOS、Windows、macOS、Linux 和 Web。
- 已实现深色、浅色主题和中英文国际化。
- 已建立 README、项目说明和厂商测试资料目录。
- 调试台已具备工作区切换、设备选择、连接控制、特征面板、收发控制台和快捷指令区域。

### 工作区基础能力

- 已建立工作区数据模型和基础工作区管理能力。
- 当前页面已能基于活动工作区展示调试环境。
- 工作区尚未完整承载设备服务、特征选择、指令集、脚本和字段映射，属于下一阶段工作。

### BLE 通信

- 已采用 `universal_ble` 完成 BLE 扫描、连接、断开、服务和特征发现。
- 已支持 Read、Notify、Indicate、Write 和 Write without response。
- 用户可自行选择订阅特征和写入目标特征。
- 已修复仅支持 Write without response 的特征不显示写入目标的问题。
- 已支持收发日志、时间戳和 HEX 输入输出。

### Linux 适配

- 已处理 BlueZ 设备对象刷新、信任设置、连接和通知相关问题。
- 当前方案仅使用 BlueZ 真正通过 D-Bus 暴露的服务和特征，不再合成 `1800/2A00`。
- 不再使用会干扰长期连接的 `gatttool` 读取方式。

### Web Bluetooth 适配

- 已支持通过 Chrome 实验性 Web Platform Features 启动 Web Bluetooth。
- 已移除所有特定设备和厂商 UUID 硬编码。
- Web 服务 UUID 由用户在设备选择前配置，支持 16 位、32 位和 128 位 UUID，并自动标准化为 128 位格式。
- 已处理 Chrome/Linux 实验性广告监听造成 BlueZ 持续扫描、阻塞 GATT 连接的问题。
- 已处理浏览器已经连接、Flutter 页面仍显示连接中的连接事件竞态。
- 特征发现已直接使用浏览器 GATT API，与厂商提供的 Web 测试工具调用链保持一致。

## Web Bluetooth 使用约束

Web Bluetooth 受浏览器安全模型限制，网页只能访问设备选择前通过 `optionalServices` 明确声明的服务。

- 顶部 Web 服务 UUID 配置中填写的是服务 UUID，不是特征 UUID。
- 需要填写本工作区将使用的全部服务 UUID。
- 修改服务 UUID 后必须重新扫描，并在 Chrome 设备选择器中重新选择设备，浏览器才会重新授予服务访问权限。
- 浏览器不会向网页暴露未声明服务的特征，无法在连接后无权限地枚举完整 GATT 数据库。

## 下一步计划

### 1. 完善工作区模型和持久化

- 为工作区增加设备名称、服务 UUID、默认写入特征和默认订阅特征。
- 将指令集、发送前脚本、接收后脚本和数据映射纳入工作区配置。
- 将 Web 服务 UUID 配置迁移到工作区，而不是只保存在页面内存。
- 使用本地 JSON 文件保存工作区，提供版本字段和向后兼容策略。

### 2. 实现工作区导入导出

- 支持导出单个工作区为 JSON 文件。
- 支持导入、格式校验和配置版本校验。
- 提供可复用的示例工作区，包含服务、读写特征、通知特征与基础指令。

### 3. 建立数据处理基础库

- 完成 HEX 编解码、ASCII/UTF-8 转换和字节序工具。
- 实现 XOR、SUM、CRC8、CRC16 和 CRC32。
- 将发送和接收处理抽象为稳定的回调链路，为脚本引擎预留输入输出协议。

### 4. 接入脚本引擎

- 定义发送前 `beforeSend(hex)` 和接收后 `afterReceive(hex)` 的脚本契约。
- 评估可同时覆盖 Android、iOS、Windows、macOS 和 Web 的 JavaScript 引擎方案。
- 提供 CRC、帧头帧尾、异或加密等示例脚本。
- 增加脚本执行错误日志、超时和输入输出预览。

### 5. 增强控制台和数据映射

- 增加 HEX、ASCII、UTF-8 和 JSON 显示模式。
- 支持按方向、特征 UUID、时间范围筛选日志。
- 支持日志导出。
- 支持将原始数据映射为结构化字段，并展示温度、电量、状态位等业务数据。

### 6. 测试和发布准备

- 补充服务层测试，覆盖 Web 服务权限、特征发现、断连重连、订阅和无响应写入。
- 建立 Linux、Android、iOS、Windows、macOS 和 Web 的真机回归清单。
- 在进入脚本与工作区阶段前，整理当前工作树并提交“BLE 基础通信可用”的阶段性提交。
